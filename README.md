# 🏎️ Formula One Hub

A modern and responsive Formula One-inspired website developed using **HTML5** and **CSS3**.

The website provides an engaging experience for Formula One enthusiasts by showcasing drivers, constructors, FIA governance, team history, and the upcoming 2026 Formula One regulations.

---

## 🚀 Features

- Responsive Design
- Modern UI/UX
- Dedicated Drivers Page
- Teams Page
- Team History
- FIA Governance
- 2026 Formula One Regulations
- Interactive Navigation
- Hover Effects
- Mobile Friendly Layout

---

## 🛠 Technologies Used

- HTML5
- CSS3
